# TENSA Engineering Website

This repository contains the public website for TENSA Engineering.

Domain:

    tensaengineering.dev

TENSA Engineering is the public umbrella, knowledge hub, and information architecture layer for the NeuroCore, Argus ACLI, and Argus Lab ecosystem.

This website starts as a simple static site, but it is not intended to remain a small landing page.

The long-term goal is for tensaengineering.dev to become the central public destination for controlled AI systems, persistent local AI, real-system AI operations, NeuroCore, Argus ACLI, Argus Lab, and the engineering philosophy behind them.

---

## Purpose

The TENSA Engineering website exists to organize and explain the full ecosystem in a way that is clear, searchable, expandable, and useful to both technical and non-technical readers.

The site should eventually help people understand:

- how to make AI useful on real systems
- how to give AI persistence and long-term memory
- how to preserve continuity across long-running projects
- how to separate intelligence from authority
- how to connect AI to tools safely
- how to govern execution
- how to build local-first AI systems
- how to structure AI operations
- how to avoid context drift
- how NeuroCore works
- how Argus ACLI works
- how Argus Lab trains users and validates diagnostic intelligence

The website should grow into a structured knowledge base, not one giant document.

## Core Positioning

TENSA Engineering builds controlled AI systems for real environments.

The deeper vision is not only AI governance.

The deeper vision is persistent, local AI that can understand real environments, remember work over time, interact with tools safely, and support long-running technical projects without constant context rebuilding.

A core lesson behind NeuroCore is:

> Intelligence without continuity is fragile.

A core principle behind the architecture is:

> AI can reason, but authority must be governed.

The website should explain both ideas clearly.

Control is not the original vision of NeuroCore.

Control is what the original vision required once persistent AI began interacting with real systems.

## Information Architecture Goal

The intended public flow is:

1. TENSA Engineering explains the overall ecosystem.
2. NeuroCore explains the platform and architecture.
3. Argus ACLI explains the first practical product.
4. Argus Lab explains the future training and validation environment.
5. GitHub proves the engineering.
6. Video and social content drive discovery.
7. The knowledge base explains the philosophy, architecture, and lessons learned.

This structure prevents every repo, website, or profile from trying to explain everything at once.

## Design Principles

The site should remain:

- clear
- structured
- expandable
- SEO-conscious
- technical but understandable
- honest about current status
- grounded in real engineering work
- free of hype-heavy AI marketing
- useful to builders, learners, and technical decision-makers

Tone should be:

- professional
- practical
- builder-focused
- technically credible
- approachable to people new to local AI

Avoid:

- corporate fluff
- exaggerated product claims
- pretending unfinished systems are complete
- burying visitors in architecture too early
- making every page explain the entire ecosystem
